# プライバシーポリシー - Raindrop Shortcut

最終更新日: 2026年8月30日

## はじめに

「Raindrop Shortcut」（以下「本拡張機能」）は、ユーザーのプライバシーを尊重し、個人情報の保護に努めます。本プライバシーポリシーは、本拡張機能におけるデータの取り扱いについて説明します。

## 収集するデータ

本拡張機能は、個人情報を自動的に収集することはありません。メールアドレスとお名前は、利用者がお問い合わせフォームに入力して送信したときだけ受け取ります（「お問い合わせフォーム」の項を参照）。

## ローカルに保存するデータ

本拡張機能は、以下のデータをユーザーの端末内に保存します。

- `chrome.storage.local`:
  - OAuth アクセストークン・リフレッシュトークン（Raindrop.io との認証用）
  - 選択中のコレクション情報
  - テーマ設定（自動 / ライト / ダーク）
  - リンクの開き方設定（新しいタブ / 現在のタブ）
  - ブックマーク一覧のローカルキャッシュ（popup 再表示の高速化目的、TTL 5 分）
- `window.localStorage`（キー `kagayoi-support-session`）:
  - お問い合わせ用のメールアドレス、Kagayoi Support のアクセストークン、有効期限

Raindrop.io の OAuth トークンとブックマーク・コレクション情報は、同サービスの認証・API 通信にのみ使用します。ブックマークのドメイン名だけは、下記のとおり favicon 取得時に Google Favicon Service へ送信します。お問い合わせセッションはブラウザ再起動後も返信確認に使えるよう保存し、有効期限切れまたは Kagayoi Support が認証を拒否したときに削除します。Raindrop.io からのログアウトでは、別サービスの認証情報であるお問い合わせセッションは削除しません。

## データの共有

本拡張機能は、データを販売せず、広告・解析・信用力判定の目的で使用または第三者へ共有しません。favicon 取得時のドメイン名の送信先は Google Favicon Service です。お問い合わせの内容は開発者（Kagayoi）のサポート窓口だけが受け取り、問い合わせ対応にのみ使用します。

## ネットワーク通信

本拡張機能は、以下の目的でのみ外部通信を行います。

- **raindrop.io** — OAuth 2.0 認証（ログイン・トークン更新）
- **api.raindrop.io** — ブックマーク・コレクション情報の取得
- **www.google.com (Favicon Service)** — ブックマーク一覧に表示する favicon 画像の取得のため、各ブックマークのドメイン名のみを送信します。ブックマーク自体のタイトル・URL・その他の個人識別情報は送信しません。
- **fonts.googleapis.com / fonts.gstatic.com (Google Fonts)** — ポップアップ UI のフォント (IBM Plex Sans JP / IBM Plex Mono) を取得するため、ブラウザがフォント定義 CSS とフォントファイル (woff2) を読み込みます。ユーザーのブックマーク情報は送信しません。フォントは初回取得後ブラウザキャッシュされます。
- **support.kagayoi.com** — 下記のお問い合わせフォームを送信したときだけ通信します。

上記以外のサーバーとの通信は一切行いません。

## お問い合わせフォーム

設定画面の「お問い合わせ」ボタンから送信したときだけ、次の情報を Kagayoi Support（`https://support.kagayoi.com`）へ送信します。ボタンを押さない限り、この通信は発生しません。

- 入力されたメールアドレス、お名前（任意）、問い合わせ種別、件名、本文
- 製品ID、拡張機能のバージョン、ロケール

初回はメールで届く6桁の確認コードを Kagayoi Support へ送信して本人確認します。認証後の問い合わせと返信は、利用者本人とサポート担当者が確認できるよう Kagayoi Support に保存します。ブックマーク、コレクション情報、Raindrop.io の認証トークンは送信しません。

## 権限の使用目的

- **identity**: Raindrop.io の OAuth 2.0 認証フローを実行するために使用します。
- **storage**: 認証トークン、コレクション選択、テーマ設定、リンク設定、ブックマークキャッシュをローカルに保存・復元するために使用します。
- **alarms**: 選択中コレクションのブックマークキャッシュを5分間隔で更新するために使用します。
- **host_permissions (api.raindrop.io, raindrop.io)**: Raindrop.io の公式 API からブックマーク・コレクション情報を取得し、OAuth 認証のトークン交換を行うために使用します。
- **host_permissions (support.kagayoi.com)**: お問い合わせのメール確認、送信、受付結果の取得を行うために使用します。フォームを送信しない限り通信は発生しません。

## お問い合わせ

本プライバシーポリシーに関するご質問は、Chrome Web Store のサポートページよりお問い合わせください。
