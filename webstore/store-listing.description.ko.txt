도구 모음의 아이콘을 클릭하기만 하면 Raindrop.io에 저장한 북마크를 간결한 목록으로 보여 주는 Chrome 확장 프로그램입니다.

■ 주요 기능

・한 번의 클릭으로 북마크 목록 표시
  도구 모음의 아이콘을 클릭하면 선택한 컬렉션의 북마크가 제목순으로 표시됩니다.

・컬렉션(폴더) 선택
  설정 화면에서 Raindrop.io의 컬렉션 트리에서 표시할 대상을 선택할 수 있습니다.
  하위 컬렉션도 계층의 깊이와 상관없이 선택할 수 있으며, '전체'를 선택하면 모든 북마크가 표시됩니다.

・증분 검색
  검색창에 입력하면 표시 중인 북마크를 제목이나 도메인 이름으로 좁혀 줍니다.

・링크 열기 방식 전환
  북마크를 '새 탭'에서 열지 '현재 탭'에서 열지 설정에서 선택할 수 있습니다.

・빠른 표시(로컬 캐시)
  선택한 컬렉션의 북마크 목록을 백그라운드에서 5분마다 가져와 기기에 저장합니다.
  아이콘을 클릭하면 저장된 목록이 바로 표시되며, 마지막으로 가져온 지 5분 이상 지났다면 목록을 표시한 채로 최신 목록을 가져옵니다.

・다크 모드 지원
  테마를 '자동(OS 설정을 따름)', '라이트', '다크' 중에서 선택할 수 있습니다.

・간결한 표시
  파비콘 + 제목 + 도메인 이름을 한 줄로 표시하므로, 북마크가 많아도 한눈에 보기 쉬운 레이아웃입니다.

・키보드 조작
  북마크와 컬렉션은 Enter / Space 키로도 선택할 수 있습니다.

・OAuth 2.0 인증
  Raindrop.io의 인증 화면에서 로그인하여 연결합니다. 확장 프로그램에 비밀번호를 입력할 필요가 없습니다.
  로그아웃하면 저장된 로그인 정보와 북마크 목록 캐시가 기기에서 삭제됩니다.

・문의하기
  설정 화면 하단에서 이 확장 프로그램에 대한 문의를 보낼 수 있습니다. 처음에는 이메일로 받은 확인 코드로 본인 확인이 필요합니다.

■ 사용 방법

1. Chrome 웹 스토어에서 설치
2. 도구 모음의 아이콘을 클릭한 다음 'Raindrop.io로 로그인' 버튼 누르기
3. Raindrop.io 계정으로 인증(처음 한 번만)
4. 북마크 목록이 표시됩니다
5. 설정(⚙ 아이콘)에서 표시할 컬렉션, 링크 열기 방식, 테마를 변경할 수 있습니다
