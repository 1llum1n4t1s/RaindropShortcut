【ストアの掲載情報】タブ
------------------------------------------------------------

■ 名前（30文字以内）
Raindrop Shortcuts

■ 概要（132文字以内）
Raindrop.io のブックマークをすばやく検索・アクセスできる拡張機能。コレクション選択・検索フィルタ・ダークモード対応。

■ 説明（16,000文字以内）
Raindrop.io に保存したブックマークを、ツールバーのアイコンをクリックするだけでコンパクトに一覧表示するChrome拡張機能です。

■ 主な機能

・ワンクリックでブックマーク一覧
  ツールバーのアイコンをクリックすると、選択中のコレクションのブックマークがタイトル順に一覧表示されます。

・コレクション（フォルダ）選択
  設定画面でRaindrop.ioのコレクションツリーから表示対象を選べます。
  サブコレクションも階層の深さにかかわらず選べ、「すべて」を選ぶと全ブックマークを表示します。

・インクリメンタル検索
  検索欄に入力すると、表示中のブックマークをタイトル・ドメイン名で絞り込みます。

・リンクの開き方切替
  ブックマークを「新しいタブ」で開くか「現在のタブ」で開くかを、設定で選べます。

・高速表示（ローカルキャッシュ）
  選択中のコレクションのブックマーク一覧をバックグラウンドで5分ごとに取得し、端末内に保存します。
  アイコンをクリックすると保存済みの一覧をすぐに表示し、最後の取得から5分以上経っている場合は、表示したまま最新の一覧を取得します。

・ダークモード対応
  テーマを「自動（OSの設定に追従）」「Light」「Dark」から選べます。

・コンパクト表示
  favicon + タイトル + ドメイン名の1行表示で、大量のブックマークも一覧しやすいレイアウトです。

・キーボード操作
  ブックマークやコレクションは、Enter / Space キーでも選べます。

・OAuth 2.0 認証
  Raindrop.io の認証画面でログインして接続します。パスワードを拡張機能に入力する必要はありません。
  ログアウトすると、保存したログイン情報とブックマーク一覧のキャッシュを端末から消去します。

・お問い合わせ
  設定画面の下部から、この拡張機能についてのお問い合わせを送信できます。初回はメールで届く確認コードによる本人確認が必要です。

■ 使い方

1. Chrome Web Storeからインストール
2. ツールバーのアイコンをクリック →「Raindrop.io でログイン」ボタンを押す
3. Raindrop.ioアカウントで認証（初回のみ）
4. ブックマーク一覧が表示されます
5. 設定（⚙アイコン）から、表示するコレクション・リンクの開き方・テーマを変更できます

【プライバシーへの取り組み】タブ
------------------------------------------------------------

■ このアイテムに単一の目的はありますか？
はい

■ 単一の目的の説明
Raindrop.io に保存されたブックマークをブラウザのポップアップで一覧表示し、すばやくアクセスする

■ データの使用に関する開示

  ・個人を特定できる情報を収集しますか？
    はい。設定画面のお問い合わせフォームを利用者が送信したときだけ、入力されたメールアドレスとお名前（任意）を Kagayoi Support へ送信します。

  ・認証情報を扱いますか？
    はい。Raindrop.io の OAuth アクセストークンとリフレッシュトークンを、ログイン状態の維持と API 通信のため端末内に保存します。

  ・個人的なコミュニケーションを収集しますか？
    はい。お問い合わせフォームを利用者が送信したときだけ、入力された問い合わせ種別・件名・本文を Kagayoi Support へ送信し、問い合わせ対応に使用します。

  ・上記以外のデータ（健康に関する情報・財務状況や支払いに関する情報・位置情報・ウェブ履歴・ユーザーのアクティビティ・ウェブサイトのコンテンツ）を収集しますか？
    いいえ

  ・ユーザーのデータをどのように扱いますか？
    - ユーザーデータの販売: しない
    - ユーザーデータの本来の目的以外への使用や転送: しない
    - 信用力の判定や貸付目的での使用や転送: しない
    - お問い合わせ認証セッション: メールアドレス、Kagayoi Support のアクセストークン、有効期限を端末の localStorage に保存し、有効期限切れまたは認証拒否時に削除

■ 権限の正当性

  alarms:
  ユーザーが選択したRaindrop.ioコレクションのブックマーク情報をバックグラウンドで5分間隔に更新し、拡張機能のポップアップを開いた際に一覧をすぐ表示できるようにするために使用します。アラームはブックマークキャッシュの定期更新にのみ使用し、通知の表示、広告、トラッキング、その他の目的には使用しません。

  identity:
  Raindrop.io の OAuth 2.0 認証フローを実行するために使用します。ユーザーがログインボタンをクリックした際にのみ認証ウィンドウを表示します。

  storage:
  Raindrop.io の認証トークン、選択中のコレクション、テーマ設定、リンクの開き方、ブックマーク一覧のキャッシュを端末内（chrome.storage.local）に保存するために使用します。認証トークンは Raindrop.io との通信にのみ使用し、開発者のサーバーへは送信しません。

  ホスト権限:
  api.raindrop.io / raindrop.io: Raindrop.io の公式 API からブックマーク・コレクション情報を取得し、OAuth 認証のトークン交換・更新を行うために使用します。support.kagayoi.com: 利用者が設定画面のお問い合わせフォームを送信したときだけ、メール確認と問い合わせ内容の送信に使用します。ブックマークや Raindrop.io の認証トークンは送信しません。

■ プライバシーポリシー URL
https://raindropshortcuts.kagayoi.com/privacy

■ 外部サーバーとの通信について
本拡張機能は以下の外部サーバーと通信します。
- raindrop.io / api.raindrop.io: ブックマーク・コレクション情報の取得および OAuth 認証
- www.google.com (Favicon Service): ブックマーク一覧の favicon 画像を取得するため、各ブックマークのドメイン名のみを送信します
- fonts.googleapis.com / fonts.gstatic.com (Google Fonts): ポップアップ UI のフォント定義とフォントファイルを取得します。ブックマーク情報は送信しません
- support.kagayoi.com (Kagayoi Support): 利用者がお問い合わせフォームを送信したときだけ、入力された連絡先と問い合わせ内容を送信します

■ リモートコードを使用していますか？
いいえ
（すべてのコードは拡張機能パッケージ内に含まれており、外部からのコード読み込みは一切行いません。）
